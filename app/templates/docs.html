Peer Tutoring API

API REST local con JSON. Descargar OpenAPI 3.0 e importar en Postman.

GET lista; POST crea. GET /{id} consulta; PATCH /{id} actualiza; DELETE /{id} elimina si no hay dependencias ni historial protegido. Habilitaciones usa /{id_tutor}/{codigo_curso}.

Consultas y errores

Listas: page=1, per_page=20 (máximo 100), q y filtros por columna. Sesiones admite id_estudiante, codigo_curso e id_tutor. Filtros temporales: desde y hasta, fechas ISO con zona. El inicio se incluye y el fin se excluye.

200 consulta/edición; 201 creación; 204 eliminación; 400 entrada inválida; 404 no encontrado; 409 conflicto de negocio o integridad. Ante un error no se guardan cambios parciales.

Programar una sesión

POST /api/v1/sesiones
{"id_solicitud":1,"id_tutor":1,
 "inicio":"2026-11-16T10:00:00-05:00",
 "fin":"2026-11-16T11:00:00-05:00","lugar":"Sala A"}

La solicitud debe estar pendiente; tutor habilitado, disponible y sin cruces de horario. Completar o cancelar con PATCH {"estado":"completada"} o {"estado":"cancelada"}. Solo se completa después de fin. La solicitud cambia automáticamente. No se editan sesiones terminales.

Reportes

GET /api/v1/reportes/demanda?desde=...&hasta=...: solicitudes por curso. GET /api/v1/reportes/desempeno?desde=...&hasta=...: completadas, evaluadas y promedio por tutor.

Prototipo de operador local, sin autenticación. No exponer a Internet ni usar datos reales.
